# 도인전 개인정보처리방침

시행일: 2026년 10월 8일

「도인전」(이하 "게임")은 이용자의 개인정보를 수집하지 않습니다.

## 1. 수집하는 정보
게임은 이름, 이메일, 전화번호, 위치, 기기 식별자 등 어떤 개인정보도 수집하거나 서버로 보내지 않습니다.

## 2. 기기에 저장되는 정보
캐릭터, 진행 상황, 소리 설정 같은 게임 기록은 이용자의 기기 안(앱 저장공간)에만 저장됩니다. 이 기록은 게임을 진행하는 데만 쓰이며, 개발자를 포함한 누구에게도 전송되지 않습니다. 앱을 삭제하면 기록도 함께 지워집니다.

## 3. 의견 보내기(이용자가 직접 보낼 때만)
게임 안 「의견 보내기」를 누르면 이용자 기기의 메일 앱이 열리고, 본문에 적은 의견과 함께 게임 상태(게임 버전, 캐릭터 경지 · 위치, 최근 게임 기록, 게임 오류 기록, 화면 크기와 기기 종류)가 들어갑니다. 무엇이 들어갔는지 메일 앱에서 직접 확인하고 지울 수 있으며, 보낼지 말지는 이용자가 정합니다. 게임이 스스로 무언가를 보내지는 않습니다. 받은 메일은 버그를 고치고 게임을 개선하는 데만 쓰고, 제3자에게 제공하지 않으며, 요청하면 지웁니다.

## 4. 제3자 제공 및 광고
게임에는 광고, 분석 도구, 외부 로그인 기능이 없으며, 어떤 정보도 제3자에게 제공하지 않습니다.

## 5. 아동의 개인정보
게임은 개인정보를 수집하지 않으므로 아동의 개인정보도 수집하지 않습니다.

## 6. 방침의 변경
이 방침이 바뀌면 이 페이지에 바뀐 내용과 시행일을 알립니다.
